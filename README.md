Ridiculous at First Glance, Real by the Second: a one-sentence startup pitch for funerals for dead houseplants — tiny coffins, eulogies, the works — sold to guilty millennials who pay $29 for closure instead of buying another fern to kill. Absurd on first hearing, obvious on the second: grief, guilt, and a price cheaper than a replacement plant.

The program is deterministic: it always writes the same single sentence to `/output/entry.txt`, well inside the gate's 1–200 character limit, with nothing to set up — the pitch is the whole product.

## Run it

```sh
node main.ts
```
